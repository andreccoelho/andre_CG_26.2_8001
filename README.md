# Computação Gráfica — IBM0168/8001

## Sobre a disciplina
 
A disciplina apresenta os conceitos fundamentais da Computação Gráfica, abordando desde a manipulação de imagens até transformações geométricas 2D e 3D, projeções e visualização de objetos.
 
**Linguagens utilizadas:** Python, OpenGL, Blender e JavaScript
 
**Tecnologias utilizadas:** Visual Studio Code e GitHub
